# Tidy v0.2.1

This release improves meeting answers and notes, refreshes Tidy's interface and branding, and fixes AI status messages and recording meters.

## Meeting intelligence

- Meeting overviews draw context from across the conversation, helping prevent a passing remark from becoming the apparent subject of the meeting.
- Transcript passages retain nearby speaker turns. Specific questions combine text and semantic search, with client and meeting filters preserved.
- Answers check individual claims against quoted evidence, link to their sources and show how much of the selected library was used. Unsupported questions can return an insufficient-evidence response.
- Notes use topic headings, decisions, next steps and open questions. Existing notes can be regenerated.
- Additional checks target invented numbers, confused responsibility and promises incorrectly described as completed work.
- Fixed the local embedding runtime's batch configuration for longer transcript passages.

## Interface and reliability

- New Tidy app icon, refreshed colours and typography, and updated home, navigation, planner and settings screens.
- Meeting-library progress shows preparation and indexing status.
- AI failures display readable messages instead of `[object Object]`, including after navigating away from model setup or the assistant.
- Recording meters respond to measured microphone and system-audio levels.
- Current application identifiers and helpers use Tidy, with compatibility metadata retained to find existing workspaces.

## Installing and upgrading

Download **Tidy_0.2.1_aarch64.dmg**, open it and drag Tidy into Applications. This installer is for Apple Silicon Macs (M1 and newer). The configured minimum is macOS 14.4; release checks were performed on macOS 26.5.2, not every supported OS version.

The app and DMG are signed with Developer ID, notarised by Apple and stapled. Signature and Gatekeeper checks include the app inside the DMG. SHA256SUMS.txt accompanies the installer.

Existing transcripts and notes remain in place. Older meeting indexes are queued for rebuilding; keep local AI enabled and Tidy open while preparation completes. Use **Regenerate notes** to update existing summaries. AI models are downloaded separately through setup.

macOS may request microphone and screen-recording permissions again because the application identifier changed. Existing MCP integrations should use the updated registration command in Tidy Settings.

## Validation

80 front-end tests, 42 shared-core tests and 14 native unit tests passed. A synthetic client-handover regression also passed using the real local models and retrieval pipeline, covering the reported passing-remark failure, responsibility, client isolation, unanswered questions and rejected proposals.

These checks do not establish perfect AI accuracy. Source transcripts remain available for review, and large-library answers disclose sampled coverage. See [AI quality checks](https://github.com/REllwood/Tidy/blob/v0.2.1/docs/AI-QUALITY.md) for evaluation details and limitations.
