Tidy v0.3.0 adds recording history, more local models and in-app updates.

## Changes

- Review meetings by client and date, export their transcripts and view earlier text versions.
- Re-transcribe retained audio with a different Whisper model or language setting. Progress and cancellation are available, and existing edits are preserved.
- Choose from 12 Whisper transcription options and six Qwen answer models, from 0.6B to 32B. Settings shows download sizes, suggested RAM and filters for smaller and larger models.
- Check for updates in Settings. Tidy prompts when a new version is available, verifies the download, saves pending editor changes and restarts after installation. Recording and transcription block installation.
- Audio retention is off by default. Enable **Settings → Recording → Keep meeting audio** before recording to keep it for later. This does not remove previously saved audio.
- Improved audio mixing, transcription controls, loading feedback and public-facing wording. Local Forge drafts are excluded from the repository.

## Install or upgrade

Download **Tidy_0.3.0_aarch64.dmg**, open it and drag Tidy into Applications.
This release is for Apple Silicon Macs. The configured minimum is macOS 14.4.
The app and DMG are Developer ID signed and notarised by Apple.

Users on v0.2.1 or earlier need to install this release manually once. Later
updates can use the new in-app updater. Existing notes and transcripts remain
in place. Model weights are downloaded separately when selected in Settings.

## Limits

Re-transcription requires retained audio; this release cannot recover recordings
removed by older versions. With audio retention off, temporary audio is discarded
after processing even if transcription fails. Audio is buffered until Stop, so a
crash during recording can lose the unfinished capture.

RAM suggestions are estimates. The full model range has not been benchmarked
across Mac hardware, and larger models do not guarantee accurate meeting answers.

## Checks

The source passed 85 front-end, 46 shared-core and 24 native unit tests. Additional
checks covered real Whisper transcription and cancellation, update signature
verification and tamper rejection, and installation of the signed update archive
into an isolated app fixture. The app inside the DMG passed signature, notarisation
and Gatekeeper checks on macOS 26.5.2. The updater's administrator prompt and restart
with a live user workspace have not been exercised on a separate Mac.
